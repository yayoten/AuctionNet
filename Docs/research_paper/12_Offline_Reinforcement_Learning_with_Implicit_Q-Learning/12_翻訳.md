## Abstract

*"Offline reinforcement learning requires reconciling two conflicting aims: …"*

オフライン強化学習は、2つの相反する目標の両立を要求する。データセットを収集した行動方策を改善する方策を学習することと、同時に、分布シフトによる誤差を避けるために、行動方策からの逸脱を最小化することである。このトレードオフは決定的に重要である。現在のほとんどのオフライン強化学習の手法は、方策を改善するために、学習中に見たことのない行動の価値を問い合わせる必要があり、したがって、これらの行動を分布内に制約するか、さもなければその価値を正則化する必要があるからである。

*"We propose a new offline RL method that never needs to evaluate actions outside of the dataset, …"*

我々は、**データセットの外の行動を評価する必要が決してない**が、それでも汎化を通じて、学習した方策がデータの中の最良の振る舞いを大幅に改善することを可能にする、新しいオフライン RL の手法を提案する。我々の研究の主な洞察は、最新の方策からの見たことのない行動を評価する代わりに、状態価値関数を、行動によって決まるランダム性を持つ確率変数として扱い（過度の楽観を避けるために、動態については依然として積分する）、その後、この確率変数の、状態を条件とする**上側のエクスペクタイル**をとって、その状態での最良の行動の価値を推定することで、方策改善のステップを暗黙的に近似できる、ということである。これは、関数近似器の汎化能力を活用して、この見たことのない行動で Q 関数を直接問い合わせることなく、与えられた状態で利用可能な最良の行動の価値を推定する。

*"Our algorithm alternates between fitting this upper expectile value function and backing it up into a Q-function, without any explicit policy. …"*

我々のアルゴリズムは、明示的な方策を一切持たずに、この上側のエクスペクタイルの価値関数の当てはめと、それを Q 関数にバックアップすることを交互に行う。その後、**アドバンテージ重み付き行動クローニング**によって方策を抽出する。これもサンプル外の行動の問い合わせを避ける。我々の手法を**暗黙的 Q 学習（IQL）**と名付ける。IQL は実装が容易で、計算効率が良く、非対称な L2 損失で追加のクリティックを当てはめることしか必要としない（脚注1：我々の実装は https://github.com/ikostrikov/implicit_q_learning で入手できる）。IQL は、オフライン強化学習の標準的なベンチマークである D4RL で、最先端の性能を示す。また、IQL が、オフラインでの初期化の後に、オンラインの相互作用を使ったファインチューニングで強い性能を達成することも示す。

> **【Abstract まとめ】**
> オフライン強化学習の主流は「データ外の行動のQ値を参照してしまうので、方策を制約するかQ値を抑える」という対処だった。IQL は発想を変え、学習中にデータ外の行動を一度も評価しない。その鍵がエクスペクタイル回帰で、データにある行動のQ値の分布の「上側」を状態価値 $V(s)$ として学習することで、データ内で最良の行動の価値を近似する。方策は最後に、アドバンテージで重み付けした行動クローニングで取り出す。AuctionNet の README が学習例として最初に挙げ、論文でも中心的に扱われているベースライン（IQL）の出典である。

## 1. INTRODUCTION

*"Offline reinforcement learning (RL) addresses the problem of learning effective policies entirely from previously collected data, without online interaction (Fujimoto et al., 2019; Lange et al., 2012). …"*

オフライン強化学習（RL）は、オンラインの相互作用なしに、以前に収集されたデータのみから効果的な方策を学習する問題を扱う（Fujimoto et al., 2019; Lange et al., 2012）。これは、未学習の方策による実世界での探索が高価または危険だが、過去のデータは利用可能である、ロボティクスから物流、オペレーションズリサーチまでのさまざまな実世界の領域で、非常に魅力的である。しかし、これは大きな課題も伴う。データを収集した行動方策の水準を超えて方策を改善するには、データセットで見られたもの以外の行動の価値を推定する必要があり、これは次に、方策改善と分布シフトのトレードオフを必要とする。データの中のものとあまりに異なる行動の価値は、正確に推定される可能性が低いからである。先行する手法は一般に、方策が行動方策からどれだけ逸脱するかを制限するよう方策を制約するか（Fujimoto et al., 2019; Wu et al., 2019; Fujimoto & Gu, 2021; Kumar et al., 2019; Nair et al., 2020; Wang et al., 2020）、分布外の行動に低い価値を割り当てるよう、学習した価値関数を正則化する（Kumar et al., 2020; Kostrikov et al., 2021）ことで、これに対処する。それでも、これは、方策がどれだけ改善するかと、分布シフトによる誤推定にどれだけ脆弱かの間に、トレードオフを課す。データで見られなかった行動の価値を直接問い合わせたり推定したりする必要が決してないことで、この問題を避けるオフライン RL の手法を考案できるだろうか。

*"In this work, we start from an observation that in-distribution constraints widely used in prior work might not be sufficient to avoid value function extrapolation, …"*

本研究では、先行研究で広く使われている分布内の制約が、価値関数の外挿を避けるのに十分でないかもしれないという観察から出発し、見たことのない行動の価値を決して問い合わせることなく、**サンプル内学習**で最適方策を学習することが可能かどうかを問う。我々の手法の鍵となる考え方は、各状態について、データセットの行動の分布に関する、価値の分布の上側のエクスペクタイルを近似することである。この価値関数をエクスペクタイル回帰で当てはめることと、それを使って Q 関数を学習するためのベルマンバックアップを計算することを交互に行う。ターゲット値でサンプル外の行動を一切使わずに、SARSA 流の TD バックアップの損失関数を修正するだけで、これを行えることを示す。この Q 関数が収束したら、アドバンテージ重み付き行動クローニングを使って、対応する方策を抽出する。このアプローチは、価値関数の学習中に、分布外の行動の明示的な制約や明示的な正則化を必要としない。ただし、アドバンテージ重み付き回帰に関する先行研究（Peters & Schaal, 2007; Peng et al., 2019; Nair et al., 2020; Wang et al., 2020）で論じられているように、我々の方策抽出のステップは暗黙的に制約を強制する。

*"Our main contribution is implicit Q-learning (IQL), a new offline RL algorithm that avoids ever querying values of unseen actions while still being able to perform multi-step dynamic programming updates. …"*

我々の主な貢献は、**暗黙的 Q 学習（IQL）**である。これは、見たことのない行動の価値の問い合わせを一切避けつつ、**多段階の動的計画法の更新**を行える、新しいオフライン RL のアルゴリズムである。我々の手法は、単純な SARSA 的な TD 更新の損失関数に小さな変更を加えることで容易に実装でき、計算上非常に効率的である。さらに、我々のアプローチは、オフライン強化学習の一般的なベンチマークである D4RL で、最先端の性能を示す。特に、我々のアプローチは、いくつかの準最適な軌跡を「**つなぎ合わせる（stitch）**」ことを必要とする、困難な Ant Maze のタスクで、先行する最先端を有意に改善する。最後に、我々のアプローチがファインチューニングに適していることを示す。オフライン RL からの初期化の後、IQL は、追加の相互作用を利用して方策の性能を改善できる。

> **【第1章 まとめ】**
> 行動方策を超えるにはデータにない行動の価値を推定する必要があるが、データから離れた行動ほど推定は不正確になる。従来は方策の制約（BCQ、TD3+BC など）か価値関数の正則化（CQL など）で対処してきたが、いずれも「改善の幅」と「誤推定への脆さ」のトレードオフを抱える。IQL は、そもそもデータ外の行動の価値を問い合わせないという方針で、このトレードオフを回避しようとする。具体的には、データの行動に関する価値の分布の上側エクスペクタイルを学習し、SARSA型のTD更新の損失を少し変えるだけで多段階の動的計画法を実現する。準最適な軌跡をつなぎ合わせる必要があるタスクで特に強い。

## 2. RELATED WORK

*"A significant portion of recently proposed offline RL methods are based on either constrained or regularized approximate dynamic programming …"*

近年提案されたオフライン RL の手法のかなりの部分は、制約付きまたは正則化付きの近似動的計画法（例：Q 学習やアクター・クリティック法）に基づいており、制約や正則化項は行動方策からの逸脱を制限する役割を果たす。これらの手法を「**多段階の動的計画法**」のアルゴリズムと呼ぶ。複数の反復にわたって真の動的計画法を行い、したがって、被覆の高いデータが与えられれば、原理的には最適方策を回復できるからである。制約は、明示的な密度モデル（Wu et al., 2019; Fujimoto et al., 2019; Kumar et al., 2019）、暗黙的なダイバージェンスの制約（Nair et al., 2020; Wang et al., 2020; Peters & Schaal, 2007; Peng et al., 2019）、あるいは方策改善の目的に教師あり学習の項を加えること（Fujimoto & Gu, 2021）によって実装できる。いくつかの研究は、分布外の行動に低い価値を生むよう、Q 関数を直接正則化することも提案している（Kostrikov et al., 2021; Kumar et al., 2020）。我々の手法も多段階の動的計画法のアルゴリズムである。しかし、先行研究とは対照的に、我々の手法は、学習中に見たことのない行動で学習した Q 関数を直接問い合わせることを完全に避け、この段階での制約の必要を一切取り除く。ただし、アドバンテージ重み付き回帰（Peng et al., 2019; Nair et al., 2020）に基づく、その後の方策抽出は、暗黙的な制約を適用する。しかし、この方策は実際には価値関数の学習に影響しない。

*"In contrast to multi-step dynamic programming methods, several recent works have proposed methods that rely either on a single step of policy iteration, …"*

多段階の動的計画法の手法とは対照的に、近年のいくつかの研究は、方策反復の単一のステップに依拠し、行動方策の価値関数または Q 関数を当てはめた後に対応する貪欲方策を抽出する手法（Peng et al., 2019; Brandfonbrener et al., 2021）か、あるいは価値関数を完全に避けて行動クローニング流の目的を利用する手法（Chen et al., 2021）を提案している。これらをまとめて「**単一ステップ**」のアプローチと呼ぶ。これらの手法も、価値関数をまったく使わないか、行動方策の価値関数を学習するため、見たことのない行動を問い合わせる必要を避ける。これらの手法は実装が簡単で、D4RL の MuJoCo の移動タスクで効果的であるが、我々は、このような単一ステップの手法が、準最適な軌跡の部分を組み合わせること（「つなぎ合わせ」）を必要とする、D4RL のより複雑なデータセットで、非常に悪い性能を示すことを示す。先行する多段階の動的計画法の手法は、そのような設定ではるかに良い性能を示し、我々の手法もそうである。この区別は5.1節でより詳しく論じる。我々の手法は、単一ステップのアプローチの単純さと計算効率も共有しており、両方の種類の手法の強みの魅力的な組み合わせを提供する。

*"Our method is based on estimating the characteristics of a random variable. …"*

我々の手法は、確率変数の特性の推定に基づいている。近年のいくつかの研究は、価値関数の分布の統計量を近似することを含む。特に、**分位点回帰**（Koenker & Hallock, 2001）は、状態行動価値関数の分位点関数を推定するために、以前から強化学習で使われてきた（Dabney et al., 2018b;a; Kuznetsov et al., 2020）。我々の手法は、エクスペクタイル回帰を行うという点で関連しているが、我々の目的は、確率的な遷移から生じる価値の分布を推定することではなく、ランダムな行動に関する状態価値関数のエクスペクタイルを推定することである。これは非常に異なる統計量である。我々の目的は、異なる将来の結果によって Q 値がどう変わりうるかを決めることではなく、確率的な動態による将来の結果を平均しつつ、異なる行動によって Q 値がどう変わりうるかを決めることである。分布的 RL に関する先行研究もオフライン RL に使えるが、他の手法と同じ行動の外挿の問題に苦しみ、同様の制約や正則化を必要とするのに対し、我々の手法は必要としない。

> **【第2章 まとめ】**
> オフライン強化学習の手法を2系統に分ける。(1) 多段階の動的計画法：ベルマンバックアップを繰り返すので、データの被覆が十分なら最適方策に到達でき、軌跡のつなぎ合わせもできるが、データ外の行動のQ値を参照するため制約や正則化が必要（BCQ、TD3+BC、CQL など）。(2) 単一ステップ：行動方策のQ関数を学んで一度だけ改善する、あるいは価値関数を使わない（Decision Transformer など）。データ外の行動を参照しないので単純で安定だが、つなぎ合わせが必要なデータに弱い。IQL は、データ外の行動を参照しないという (2) の利点を保ちながら、(1) の多段階の動的計画法を行う点で両者の長所を併せ持つ。分位点回帰を使う分布的RLとは、何についての分布を見るか（遷移の確率性ではなく行動の違い）が異なる。

## 3. PRELIMINARIES（準備）

*"The RL problem is formulated in the context of a Markov decision process (MDP) …"*

RL の問題は、マルコフ決定過程（MDP）$(\mathcal{S}, \mathcal{A}, p_0(s), p(s' \mid s, a), r(s, a), \gamma)$ の文脈で定式化される。ここで $\mathcal{S}$ は状態空間、$\mathcal{A}$ は行動空間、$p_0(s)$ は初期状態の分布、$p(s' \mid s, a)$ は環境の動態、$r(s, a)$ は報酬関数、$\gamma$ は割引率である。エージェントは、方策 $\pi(a \mid s)$ に従って MDP と相互作用する。目標は、累積割引収益を最大化する方策を得ることである。

$$\pi^* = \arg\max_\pi \ \mathbb{E}_\pi \left[ \sum_{t=0}^{\infty} \gamma^t r(s_t, a_t) \ \Big| \ s_0 \sim p_0(\cdot), \ a_t \sim \pi(\cdot \mid s_t), \ s_{t+1} \sim p(\cdot \mid s_t, a_t) \right]$$

近似動的計画法に基づくオフポリシーの RL の手法は、通常、$Q(s, a)$ と表される状態行動価値関数（Q 関数）を利用する。これは、状態 $s$ と行動 $a$ から開始し、その後、方策 $\pi$ に従うことで得られる割引収益に対応する。

**オフライン強化学習** *"In contrast to online (on-policy or off-policy) RL methods, offline RL uses previously collected data without any additional data collection. …"*

オンライン（オンポリシーまたはオフポリシー）の RL の手法とは対照的に、オフライン RL は、追加のデータ収集を一切行わずに、以前に収集されたデータを使う。近年の多くのオフライン RL の手法と同様に、我々の研究は、次の損失に従って時間差分誤差を最小化する、近似動的計画法の手法の上に構築される。

$$L_{TD}(\theta) = \mathbb{E}_{(s, a, s') \sim \mathcal{D}} \left[ \left( r(s, a) + \gamma \max_{a'} Q_{\hat{\theta}}(s', a') - Q_\theta(s, a) \right)^2 \right] \tag{1}$$

ここで $\mathcal{D}$ はデータセット、$Q_\theta(s, a)$ はパラメータ化された Q 関数、$Q_{\hat{\theta}}(s, a)$ はターゲットネットワーク（例：Polyak 平均によって定義されるソフトなパラメータの更新を伴う）であり、方策は $\pi(s) = \arg\max_a Q_\theta(s, a)$ と定義される。近年のほとんどのオフライン RL の手法は、結果として得られる方策をデータの近くに保つように価値関数を正則化するよう、（上の）価値関数の損失を修正するか、$\arg\max$ の方策を直接制約する。これは重要である。分布外の行動 $a'$ は、上の目的で $Q_{\hat{\theta}}(s', a')$ に誤った値を生みえ、方策が（推定した）Q 値を最大化するよう定義されているため、しばしば過大評価につながるからである。

> **【第3章 まとめ】**
> 標準的な設定を確認する。通常のQ学習はTD誤差（式 (1)）を最小化するが、そのターゲットに含まれる $\max_{a'} Q(s', a')$ が問題の根源である。データにない行動 $a'$ のQ値は誤って高く出ることがあり、最大化はそれを選んでしまうため過大評価が起きる。既存のオフライン手法は、この損失に正則化を加えるか、$\arg\max$ をとる方策を制約することで対処する。IQL は次章で、この $\max$ をデータ外の行動に触れない形で置き換える。

## 4. IMPLICIT Q-LEARNING（暗黙的 Q 学習）

*"In this work, we aim to entirely avoid querying out-of-sample (unseen) actions in our TD loss. …"*

本研究では、TD 損失でサンプル外の（見たことのない）行動を問い合わせることを、完全に避けることを目指す。SARSA 流の目的による**適合 Q 評価**を考えることから始める。これは単に、データセットの方策 $\pi_\beta$（行動方策とも呼ばれる）の価値を学習することを目指す。

$$L(\theta) = \mathbb{E}_{(s, a, s', a') \sim \mathcal{D}} \left[ \left( r(s, a) + \gamma Q_{\hat{\theta}}(s', a') - Q_\theta(s, a) \right)^2 \right] \tag{2}$$

この目的は、式 (1) とは対照的に、サンプル外の行動の価値を決して問い合わせない（$a'$ はデータに記録された次の行動である）。本研究にとって重要な、この目的の一つの具体的な性質は、TD ターゲットの平均の統計量を予測するように $Q_\theta(s, a)$ を当てはめる、平均二乗誤差（MSE）を使うことである。したがって、無限の容量とサンプリング誤差なしを仮定すると、最適なパラメータは次を満たすはずである。

$$Q_{\theta^*}(s, a) \approx r(s, a) + \gamma \, \mathbb{E}_{s' \sim p(\cdot \mid s, a), \ a' \sim \pi_\beta(\cdot \mid s')} \left[ Q_{\hat{\theta}}(s', a') \right] \tag{3}$$

*"Prior work (Brandfonbrener et al., 2021; Peng et al., 2019) has proposed directly using this objective to learn Q^{π_β}, and then train the policy π_ψ to maximize Q^{π_β}. …"*

先行研究（Brandfonbrener et al., 2021; Peng et al., 2019）は、この目的を直接使って $Q^{\pi_\beta}$ を学習し、その後、$Q^{\pi_\beta}$ を最大化するように方策 $\pi_\psi$ を学習することを提案している。これは、TD 損失がデータセットの行動のみを使うため、分布外の行動に伴う問題を一切避ける。しかし、この手続きは、D4RL の単純な MuJoCo の移動タスクでは経験的にうまく機能するが、多段階の動的計画法の恩恵を受ける、より複雑なタスクでは、非常に悪い性能を示すことを我々は示す。次に導出する我々の手法では、この SARSA 的な目的を使うことの利点を保ちつつ、多段階の動的計画法を行い、ほぼ最適な Q 関数を学習できるように、それを修正する。

*"Our method will perform a Q-function update similar to Eqn. (2), but we will aim to estimate the maximum Q-value over actions that are in the support of the data distribution. …"*

我々の手法は、式 (2) に似た Q 関数の更新を行うが、**データ分布のサポートの中にある行動についての最大の Q 値**を推定することを目指す。決定的に重要なこととして、エクスペクタイル回帰を利用することで、学習した Q 関数をサンプル外の行動で問い合わせることなく、これを行えることを示す。正式には、我々が学習を目指す価値関数は、次で与えられる。

$$L(\theta) = \mathbb{E}_{(s, a, s') \sim \mathcal{D}} \left[ \left( r(s, a) + \gamma \max_{\substack{a' \in \mathcal{A} \\ \text{s.t.} \ \pi_\beta(a' \mid s') > 0}} Q_{\hat{\theta}}(s', a') - Q_\theta(s, a) \right)^2 \right] \tag{4}$$

我々のアルゴリズムである暗黙的 Q 学習（IQL）は、データセットの中の状態行動の組でのみ Q 関数を評価しつつ、この目的を推定することを目指す。この目的のために、ターゲット値の、状態を条件とするエクスペクタイルを推定するように $Q_\theta(s, a)$ を当てはめることを提案し、特定のエクスペクタイルが上で定義した最大化を近似することを示す。4.4節で、このアプローチが理論上、多段階の動的計画法を行うことを示し、5.1節で、実際にもそうであることを示す。

### 4.1 EXPECTILE REGRESSION（エクスペクタイル回帰）

*"Practical methods for estimating various statistics of a random variable have been thoroughly studies in applied statistics and econometrics. …"*

確率変数のさまざまな統計量を推定するための実用的な手法は、応用統計学と計量経済学で徹底的に研究されてきた。ある確率変数 $X$ の $\tau \in (0, 1)$ **エクスペクタイル**は、非対称な最小二乗問題の解として定義される。

$$\arg\min_{m_\tau} \ \mathbb{E}_{x \sim X} \left[ L_2^\tau(x - m_\tau) \right], \qquad \text{ここで} \quad L_2^\tau(u) = |\tau - \mathbb{1}(u < 0)| \, u^2$$

すなわち、$\tau > 0.5$ のとき、この非対称な損失関数は、$m_\tau$ より小さい $x$ の値の寄与の重みを下げ、より大きな値により多くの重みを与える（Fig. 1 左を参照）。エクスペクタイル回帰は、分位点回帰（Koenker & Hallock, 2001）と密接に関係している。分位点回帰は、強化学習で広く使われている（Dabney et al., 2018b;a）、分布の分位点を推定するための一般的な技術である（脚注2：我々の手法は分位点でも導出できるが、先行研究（Dabney et al., 2018b;a）とは異なり、すべてのエクスペクタイル／分位点を学習することに関心があるわけではないため、単一のエクスペクタイルを推定するほうが便利である。これは、標準的な RL の手法ですでに使われている MSE 損失への単純な修正を伴うだけだからである。対応する $\ell_1$ 損失を持つ分位点回帰より、いくらかうまく機能することが分かった）。分位点回帰の損失は、非対称な $\ell_1$ 損失として定義される。

この定式化を使って、条件付き分布のエクスペクタイルを予測することもできる。

$$\arg\min_{m_\tau(x)} \ \mathbb{E}_{(x, y) \sim \mathcal{D}} \left[ L_2^\tau(y - m_\tau(x)) \right]$$

Fig. 1（右）は、単純な2次元の分布での条件付きエクスペクタイル回帰を図示している。この目的は、確率的勾配降下法で最適化できることに注意されたい。これは不偏な勾配を与え、標準的な機械学習のライブラリで容易に実装できる。

> **Figure 1：** 左：エクスペクタイル回帰に使われる非対称な二乗損失。$\tau = 0.5$ は標準的な平均二乗誤差の損失に対応し、$\tau = 0.9$ は正の差により多くの重みを与える。中央：正規分布のエクスペクタイル。右：2次元の確率変数の、状態を条件とするエクスペクタイルを推定する例。各 $x$ は $y$ についての分布に対応する。エクスペクタイル回帰で、この確率変数の最大値を近似できる。$\tau = 0.5$ は分布の条件付き平均の統計量に対応し、$\tau \approx 1$ は、サポート内の $y$ の値についての最大値の演算子を近似する。

### 4.2 LEARNING THE VALUE FUNCTION WITH EXPECTILE REGRESSION（エクスペクタイル回帰による価値関数の学習）

*"Expectile regression provides us with a powerful framework to estimate statistics of a random variable beyond mean regression. …"*

エクスペクタイル回帰は、平均の回帰を超えて確率変数の統計量を推定する、強力な枠組みを与えてくれる。エクスペクタイル回帰を使って、式 (2) の方策評価の目的を修正し、式 (4) のように、データセットの行動に制約された行動 $a'$ についての $r(s, a) + \gamma Q_{\hat{\theta}}(s', a')$ の最大値を近似する、TD ターゲットの上側のエクスペクタイルを予測できる。これは、次のエクスペクタイル回帰の目的につながる。

$$L(\theta) = \mathbb{E}_{(s, a, s', a') \sim \mathcal{D}} \left[ L_2^\tau \left( r(s, a) + \gamma Q_{\hat{\theta}}(s', a') - Q_\theta(s, a) \right) \right]$$

*"However, this formulation has a significant drawback. …"*

しかし、この定式化には大きな欠点がある。データのサポートの中の行動に関してのみエクスペクタイルを推定する代わりに、環境の動態 $s' \sim p(\cdot \mid s, a)$ に由来する確率性も取り込んでしまう。したがって、大きなターゲット値は、必ずしもその価値を達成する単一の行動の存在を反映するとは限らず、たまたま良い状態に遷移した「**運の良い**」サンプルを反映するかもしれない。我々は、**行動の分布に関してのみ**エクスペクタイルを近似する別個の価値関数を導入することで、これを解決する。これは次の損失につながる。

$$L_V(\psi) = \mathbb{E}_{(s, a) \sim \mathcal{D}} \left[ L_2^\tau \left( Q_{\hat{\theta}}(s, a) - V_\psi(s) \right) \right] \tag{5}$$

その後、この推定値を使って、MSE 損失で Q 関数を更新できる。MSE 損失は、遷移からの確率性について平均し、上で述べた「運の良い」サンプルの問題を避ける。

$$L_Q(\theta) = \mathbb{E}_{(s, a, s') \sim \mathcal{D}} \left[ \left( r(s, a) + \gamma V_\psi(s') - Q_\theta(s, a) \right)^2 \right] \tag{6}$$

これらの損失は明示的な方策を一切使わず、SARSA 流の方策評価と同様に、両方の目的でデータセットからの行動のみを利用することに注意されたい。4.4節で、この手続きが、いくつかの仮定の下で最適な Q 関数を回復することを示す。

式 (5) と (6) の役割を整理すると、(5) は「状態 $s$ で、データにある行動のQ値のうち上のほう」を $V(s)$ に学習させ、(6) はその $V(s')$ を次状態の価値として使って $Q(s, a)$ を更新する。通常のQ学習の $\max_{a'} Q(s', a')$ を、$V(s')$ で置き換えていることになる。

### 4.3 POLICY EXTRACTION AND ALGORITHM SUMMARY（方策の抽出とアルゴリズムのまとめ）

*"While our modified TD learning procedure learns an approximation to the optimal Q-function, it does not explicitly represent the corresponding policy, …"*

我々の修正した TD 学習の手続きは、最適な Q 関数の近似を学習するが、対応する方策を明示的には表現せず、したがって、別個の方策抽出のステップを必要とする。単純さと効率を保つという精神で、方策抽出のための単純な手法を目指す。先と同様に、サンプル外の行動を使うことを避けることを目指す。そこで、**アドバンテージ重み付き回帰**（Peters & Schaal, 2007; Wang et al., 2018; Peng et al., 2019; Nair et al., 2020）を使って方策を抽出する。

$$L_\pi(\phi) = \mathbb{E}_{(s, a) \sim \mathcal{D}} \left[ \exp\left( \beta \left( Q_{\hat{\theta}}(s, a) - V_\psi(s) \right) \right) \log \pi_\phi(a \mid s) \right] \tag{7}$$

ここで $\beta \in [0, \infty)$ は逆温度である。より小さいハイパーパラメータの値では、目的は行動クローニングと同様に振る舞い、より大きい値では、Q 関数の最大値を回復しようとする。先行研究で示されているように、この目的は、分布の制約の下で Q 値を最大化する方策を学習する（Peters & Schaal, 2007; Peng et al., 2019; Nair et al., 2020）。

（式 (7) は、データの行動 $a$ を模倣する際に、アドバンテージ $Q(s, a) - V(s)$ が大きい行動ほど大きな重みを付ける、重み付きの行動クローニングである。）

**Algorithm 1　暗黙的 Q 学習（Implicit Q-learning）**

```text
パラメータ ψ, θ, θ̂, φ を初期化する

TD 学習（IQL）:
for 各勾配ステップ do
    ψ ← ψ − λ_V ∇_ψ L_V(ψ)        ▷ 式 (5): エクスペクタイル回帰で V を更新
    θ ← θ − λ_Q ∇_θ L_Q(θ)        ▷ 式 (6): MSE で Q を更新
    θ̂ ← (1 − α) θ̂ + α θ           ▷ ターゲットネットワークの更新
end for

方策の抽出（AWR）:
for 各勾配ステップ do
    φ ← φ − λ_π ∇_φ L_π(φ)        ▷ 式 (7): アドバンテージ重み付き回帰
end for
```

*"Our final algorithm consists of two stages. …"*

我々の最終的なアルゴリズムは、2つの段階からなる。第一に、価値関数と $Q$ を当てはめ、式 (5) と (6) を交互に、いくつかの勾配の更新を行う。第二に、式 (7) について確率的勾配降下法を行う。両方のステップで、Clipped Double Q-learning（Fujimoto et al., 2018）の一種を使い、$V$ 関数と方策の更新のために、2つの Q 関数の最小値をとる。最終的な手法を Algorithm 1 にまとめる。方策は価値関数に一切影響せず、したがって、抽出は TD 学習と並行して行っても、その後に行ってもよいことに注意されたい。並行した学習は、5.3節で論じるように、オンラインのファインチューニングで IQL を使う方法を提供する。

### 4.4 ANALYSIS（分析）

*"In this section, we will show that IQL can recover the optimal value function under the dataset support constraints. …"*

本節では、IQL が、データセットのサポートの制約の下で、最適価値関数を回復できることを示す。まず、単純な補題を証明し、その後、それを使って、我々のアプローチが最適価値関数の学習をどう可能にするかを示す。

**補題 1.** $X$ を、有界なサポートを持つ実数値の確率変数とし、サポートの上限を $x^*$ とする。すると、

$$\lim_{\tau \to 1} m_\tau = x^*$$

**証明の概略.** 確率変数のエクスペクタイルが同じ上限 $x^*$ を持つことを示せる。さらに、$\tau_1 < \tau_2$ であるすべての $\tau_1$ と $\tau_2$ について、$m_{\tau_1} \le m_{\tau_2}$ が得られる。したがって、極限は、有界な単調非減少関数の性質から従う。 □

*"In the following theorems, we show that under certain assumptions, our method indeed approximates the optimal state-action value Q* and performs multi-step dynamical programming. …"*

以下の定理で、一定の仮定の下で、我々の手法が実際に最適な状態行動価値 $Q^*$ を近似し、多段階の動的計画法を行うことを示す。まず、Q 関数の異なるエクスペクタイルを関係づける技術的な補題を証明し、その後、我々の手法の最適性に関する主な結果を導出する。

簡単のため、分析のために次の記法を導入する。$\mathbb{E}_{x \sim X}^\tau[x]$ を $X$ の $\tau$ エクスペクタイルとする（例：$\mathbb{E}^{0.5}$ は標準的な期待値に対応する）。すると、式 (5) と (6) の最適解にそれぞれ対応する $V_\tau(s)$ と $Q_\tau(s, a)$ を、再帰的に次のように定義する。

$$V_\tau(s) = \mathbb{E}_{a \sim \mu(\cdot \mid s)}^\tau \left[ Q_\tau(s, a) \right], \qquad Q_\tau(s, a) = r(s, a) + \gamma \, \mathbb{E}_{s' \sim p(\cdot \mid s, a)} \left[ V_\tau(s') \right]$$

**補題 2.** $\tau_1 < \tau_2$ であるすべての $s$、$\tau_1$、$\tau_2$ について、次が得られる。

$$V_{\tau_1}(s) \le V_{\tau_2}(s)$$

**証明.** 証明は、方策改善の証明（Sutton & Barto, 2018）に従う。付録 A を参照。 □

**系 2.1.** 任意の $\tau$ と $s$ について、次が成り立つ。

$$V_\tau(s) \le \max_{\substack{a \in \mathcal{A} \\ \text{s.t.} \ \pi_\beta(a \mid s) > 0}} Q^*(s, a)$$

ここで $V_\tau(s)$ は上のように定義され、$Q^*(s, a)$ は、データセットに制約された最適な状態行動価値関数であり、次のように定義される。

$$Q^*(s, a) = r(s, a) + \gamma \, \mathbb{E}_{s' \sim p(\cdot \mid s, a)} \left[ \max_{\substack{a' \in \mathcal{A} \\ \text{s.t.} \ \pi_\beta(a' \mid s') > 0}} Q^*(s', a') \right]$$

**証明.** 証明は、凸結合が最大値より小さいという観察から従う。 □

**定理 3.**

$$\lim_{\tau \to 1} V_\tau(s) = \max_{\substack{a \in \mathcal{A} \\ \text{s.t.} \ \pi_\beta(a \mid s) > 0}} Q^*(s, a)$$

**証明.** 補題1と系 2.1 を組み合わせることから従う。 □

*"Therefore, for a larger value of τ < 1, we get a better approximation of the maximum. …"*

したがって、$\tau < 1$ のより大きな値について、最大値のより良い近似が得られる。一方、それはより困難な最適化問題にもなる。そこで、$\tau$ をハイパーパラメータとして扱う。定理3で論じた性質から、我々の手法を**暗黙的 Q 学習（IQL）**と名付ける。また、我々の価値学習の手法が、**SARSA（$\tau = 0.5$）と Q 学習（$\tau \to 1$）の間の手法のスペクトル全体**を定義することも強調しておく。

> **Figure 2：** おもちゃの umaze の環境 (a) での、我々のアルゴリズムの評価。静的なデータセットが準最適な行動で大きく汚染されているとき、1ステップの方策評価は、報酬のある状態から離れるにつれてあまりに速くゼロに劣化する価値関数をもたらす (c)。我々のアルゴリズムは、SARSA 流の評価の最良の性質を、多段階の動的計画法を行う能力と組み合わせて、ほぼ最適な価値関数を学習することを目指し、最適（(b) に示す）にはるかに近い価値関数につながり、はるかに良い方策を生む (d)。

> **【第4章 まとめ】**
> 手法の中核。出発点はSARSA型の更新（式 (2)）で、次の行動 $a'$ にデータの行動を使うためデータ外を参照しないが、学べるのは行動方策の価値にとどまる。IQL は損失を非対称な二乗損失（エクスペクタイル損失）に変え、「データにある行動の中で良いもの」の価値を学ぶ。遷移の運の良さを拾わないよう、(5) 状態価値 $V(s)$ をQ値の上側エクスペクタイルとして学習、(6) $r + \gamma V(s')$ を目標に $Q(s,a)$ を通常の二乗誤差で学習、の2つに分ける。方策は (7) アドバンテージ $Q - V$ の指数で重み付けした行動クローニングで取り出す。$\tau \to 1$ で $V$ はデータのサポート内での最大Q値に収束し（定理3）、$\tau = 0.5$ ならSARSA、$\tau \to 1$ ならQ学習に対応する。ハイパーパラメータは $\tau$ と $\beta$ の2つである。

*"Our experiments aim to evaluate our method comparatively, in contrast to prior offline RL methods, …"*

我々の実験は、先行するオフライン RL の手法と対比して、我々の手法を比較評価することを目指し、特に、我々のアプローチが、単一ステップの手法と多段階の動的計画法のアプローチの両方とどう比較されるかを理解することを目指す。まず、単一ステップの手法と対比して、我々のもののような多段階の動的計画法の手法の利点を示し、一部の問題ではこの差が極めて大きくなりうることを示す。次に、D4RL（Fu et al., 2020）のベンチマークのタスクで、IQL を最先端の単一ステップと多段階のアルゴリズムと比較し、データセットの中の行動のみを使って、効果的な方策をどの程度学習できるかを調べる。単一ステップの手法がうまく機能する、ほぼ最適な軌跡を含む領域と、多段階の動的計画法を必要とする、最適な軌跡をまったく含まない領域を調べる。最後に、オフライン RL の初期化から始めてオンラインの RL でファインチューニングする際に、IQL が先行する手法とどう比較されるかを調べる。

### 5.1 THE DIFFERENCE BETWEEN ONE-STEP POLICY IMPROVEMENT AND IQL（1ステップの方策改善と IQL の違い）

*"We first use a simple maze environment to illustrate the importance of multi-step dynamic programming for offline RL. …"*

まず、単純な迷路の環境を使って、オフライン RL にとっての多段階の動的計画法の重要性を例示する。迷路は U 字型で、単一の開始状態と単一のゴール状態を持つ（Fig. 2a を参照）。エージェントは、ゴール状態に入ると10の報酬を、他のすべての遷移ではゼロの報酬を受け取る。確率0.25で、エージェントはランダムな状態に遷移し、そうでなければ指示された状態に遷移する。データセットは、1つの最適な軌跡と、一様にランダムな行動を持つ99の軌跡からなる。問題のホライズンが短いため、$\gamma = 0.9$ を使う。

*"Fig. 2 (c, d) illustrates the difference between single-step methods, in this case represented by One-step RL (Brandfonbrener et al., 2021; Wang et al., 2018) and IQL with τ = 0.95. …"*

Fig. 2 (c, d) は、単一ステップの手法（この場合、Onestep RL（Brandfonbrener et al., 2021; Wang et al., 2018）で代表される）と、$\tau = 0.95$ の IQL の違いを図示している。高報酬の状態に近い状態は依然としてより高い価値を持つが、これらの価値は、離れるにつれて、最適価値関数の場合よりはるかに速く減衰し、結果として得られる方策は非常に準最適である。IQL (d) は反復的な動的計画法を行うため、信号を正しく伝播し、価値はもはやノイズに支配されない。結果として得られる価値関数は、真の最適価値関数 (b) とよく一致する。

### 5.3 ONLINE FINE-TUNING AFTER OFFLINE RL（オフライン RL の後のオンラインのファインチューニング）

*"The policies obtained by offline RL can often be improved with a small amount of online interaction. …"*

オフライン RL で得た方策は、しばしば、少量のオンラインの相互作用で改善できる。IQL は、2つの理由から、オンラインのファインチューニングによく適している。第一に、IQL は、前節で示したように強いオフラインの性能を持ち、それが良い初期化を与える。第二に、IQL は、重み付き行動クローニングの方策抽出のステップを実装しており、これは、他の種類のオフラインの制約と比べて、より良いオンラインの方策改善を可能にすることが以前に示されている（Nair et al., 2020）。さまざまな RL のアルゴリズムのファインチューニングの能力を評価するために、まず各データセットでオフライン RL を実行し、次に100万ステップのオンラインの RL を実行し、その後、最終的な性能を報告する。オンラインのファインチューニングのために特に提案された AWAC（Nair et al., 2020）と、前節の我々の実験で先行する手法の中で最良の性能を示した CQL（Kumar et al., 2020）と比較する。正確な実験の詳細は付録 C に示す。困難な Ant Maze の D4RL の領域（Fu et al., 2020）と、Nair et al. (2020) が AWAC でのオンラインの適応を研究するために使うことを提案している、Rajeswaran et al. (2018) の高次元の器用な操作の環境を使う。結果を Table 2 に示す。Ant Maze の領域では、IQL は、オンラインのファインチューニングの後、両方の先行する手法を有意に上回る。CQL が2番目に良いスコアを達成し、AWAC は、はるかに弱いオフラインの初期化のため、比較的悪い性能を示す。器用な手のタスクでは、IQL は、relocate-binary-v0 で AWAC より有意に良く、door-binary-v0 で同等、pen-binary-v0 でわずかに悪く、全体では最良のスコアを示す。

## 6. CONCLUSION（結論）

*"We presented implicit Q-Learning (IQL), a general algorithm for offline RL that completely avoids any queries to values of out-of-sample actions during training while still enabling multi-step dynamic programming. …"*

多段階の動的計画法を可能にしつつ、学習中にサンプル外の行動の価値への問い合わせを完全に避ける、オフライン RL のための一般的なアルゴリズムである、暗黙的 Q 学習（IQL）を提示した。我々の知る限り、これは、この両方の特徴を組み合わせた最初の手法である。これには、いくつかの重要な利点がある。第一に、我々のアルゴリズムは計算上効率的である。1台の GTX1080 GPU で、100万回の更新を20分未満で行える。第二に、実装が簡単であり、標準的な SARSA 的な TD のアルゴリズムへのわずかな修正と、教師あり学習に似た単純な重み付き行動クローニングの手続きによる方策抽出しか必要としない。最後に、この手法の単純さと効率にもかかわらず、D4RL ベンチマークのすべてのタスクにわたって優れた性能を達成し、MuJoCo の移動タスクで最良の先行する手法に匹敵し、良い性能のために多段階の動的計画法が不可欠である、困難な ant maze の環境で、最先端の性能を超えることを示した。

> **【第6章 まとめ】**
> IQL は「学習中にデータ外の行動の価値を一切問い合わせない」ことと「多段階の動的計画法を行う」ことを初めて両立させた、と総括する。利点は、計算が速い（100万更新が20分未満）、実装が簡単（SARSA型TDの損失の小変更と重み付き行動クローニング）、性能が高い（移動タスクで最良手法と同等、Ant Maze で最先端超え）の3点である。
