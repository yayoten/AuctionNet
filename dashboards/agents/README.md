# agents/ — エージェントの台帳

| 場所 | 中身 | 作る人 | git |
|---|---|---|---|
| `tasks/T001/task.json` | タスク（予約）1 件。題、概要、状態、予約しているフォルダと番号、動かす端末 | `programs/agentctl.py new` | 管理する |
| `tasks/T001/指示書.md` | そのタスクの要件。チェックリスト（`- [ ]`）の印の数が、画面の「進み具合」になる | 人、または指示を出す側の Claude | 管理する |
| `tasks/T001/進捗.md` | 何をやったか、今どこか、止まった理由 | 担当の Claude | 管理する |
| `sessions/<ID>.json` | 動いている Claude 1 つ。最後に動いた時刻、編集したファイル、受けた警告 | フック（自動） | 管理しない |

1 件 1 ファイルにしているのは、台帳そのものが取り合いにならないようにするため。
使い方は [../README.md](../README.md)。
